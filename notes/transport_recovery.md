# 开发阶段传输恢复记录

开发集首轮完成了60个成功任务和12个失败任务；失败集中于本机环境代理连接异常（`ProxyError`）及少量读取超时。日志保留了所有实际尝试。直接请求的只读连接检查在不继承环境代理时成功，故 runner 增加从配置选择 `Session.trust_env` 和独立连接/读取超时的能力；异常分类使用 `requests.exceptions.ChunkedEncodingError`，每次请求日志增加 UTC 发送与接收时间。重试配置可单独覆盖，成功 task ID 通过 `--resume` 去重。

恢复开发运行时采用直连传输配置后，原12个失败任务全部成功；最终开发集72/72个任务均有成功响应。该恢复只改变传输设置与失败任务的重试，不改数据、提示文本、解码参数或评分定义。正式测试使用冻结后的正式配置，恢复配置只留作工程记录。
